# 🌊 Tidepool Keeper

A relaxing ocean ecosystem simulation game where players maintain and care for a miniature tidepool environment.

## About the Game

Tidepool Keeper is a browser-based simulation game focused on maintaining a balanced marine ecosystem. Players interact with marine life, monitor environmental conditions, and manage the overall health of their tidepool. The game offers a calm, engaging experience that encourages careful observation and thoughtful decision-making as you work to keep your tidepool thriving.

## Features

- Interactive tidepool simulation
- Marine life management and care
- Ecosystem balance monitoring
- Environmental statistics and indicators
- Interactive game interface
- Browser-based gameplay (no installation required)
- Relaxing, low-pressure gameplay experience

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No additional setup, dependencies, or installations are required.

## Project Structure

```
tidepool-keeper/
└── index.html
```

## How to Play

1. Open the game in your browser.
2. Observe the current state of your tidepool and its marine life.
3. Interact with the environment to maintain balance and keep your ecosystem healthy.
4. Monitor the environmental indicators to track the well-being of your tidepool.
5. Continue caring for your tidepool and watch your ecosystem thrive.
